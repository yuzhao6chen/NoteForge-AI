# 读《深度工作》的思考

## 原始阅读笔记

今天读《深度工作》，我发现现在很多人不是没有时间，而是注意力被短视频和社交软件切碎了。

真正重要的不是每天学多久，而是有没有连续专注的时间。

我想写给大学生和自学者，提醒他们别把努力变成碎片化打卡。

## 建议生成设置

- 平台：公众号
- 目标读者：大学生和自学者
- 写作风格：真诚、自然、有个人感
- 目标字数：1200
- 质量模式：均衡或深度打磨
- 联网搜索：可选

## 期望结果

- 生成多个选题方向。
- 把“注意力碎片化”打磨成清晰主观点。
- 输出一篇可编辑公众号草稿。
- 给出质量评分和事实风险提醒。
