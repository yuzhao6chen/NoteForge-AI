## Draft Excerpt

你以为自己缺的是时间，其实更可能缺的是一段没有被切碎的时间。

很多人的一天看起来很满：课表、消息、短视频、收藏夹、待办清单，每一项都在提醒你“快一点”。可到了晚上复盘，又很难说清楚今天到底把哪件重要的事往前推了一步。

这不是单纯的不努力。

更常见的问题是，注意力被切成了太多小块。每一次切换都不明显，但一天结束后，你会发现自己像一直在启动，却很少真正进入状态。

## Why This Example Exists

The demo is designed to prove the product flow without requiring an API key:

- Writing page can generate a visible workflow result.

- Export still writes Markdown to `backend/storage/`.
